# Components

## Overview
The `src/components` directory acts as the central UI components boundary for the application. It encapsulates all user interface building blocks, spanning core accessibility primitives, interactive widgets, tactile stationery surfaces, and procedural hand-drawn graphic elements. 

## Subdirectories & Boundaries
- ui: [./ui/README.md](./ui/README.md) - Comprehensive package of 123 tactile, stationery-themed, and Radix-based UI components (buttons, dialogs, forms, tables, corkboards, sticker boards, and procedural ink animations).
- math: Tactile mathematics manipulatives, discrete array graph paper, and parity pairing mats implementing NC.2.OA.3 and NC.2.OA.4 standards. [ArrayBoard.tsx](./math/ArrayBoard.tsx) [PairingMat.tsx](./math/PairingMat.tsx) [SupplyTray.tsx](./math/SupplyTray.tsx) [MascotCompanion.tsx](./math/MascotCompanion.tsx) [NC2OA4Wireframe.tsx](./math/NC2OA4Wireframe.tsx) [NC2OA3Wireframe.tsx](./math/NC2OA3Wireframe.tsx)
