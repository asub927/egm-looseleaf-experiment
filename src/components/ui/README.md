# UI Components

## Overview

The `src/components/ui` package provides a design system of 123 composable React 19 UI components with a distinct tactile stationery, paper-craft, and ink-pen aesthetic. Constructed upon Radix UI primitives, Tailwind CSS v4, Lucide icons, and the custom `@/lib/ink` engine, this component package unifies standard interactive application controls (buttons, dialogs, forms, tables, carousels) with tactile desk elements (corkboards, sticky notes, torn paper stubs, wax seals, stamps, sketchpads, and animated typewriter effects).

Key architectural principles across the package include:

- **Procedural Ink & Texture Integration**: Visual elements integrate with `@/lib/ink` (`useInk`) to project procedural SVG stroke outlines, hand-drawn line boil oscillations, and press-sink physics.
- **Accessible Primitives**: Dialogs, menus, tooltips, popovers, and accordions wrap headless Radix UI components, ensuring full WAI-ARIA compliance, focus trapping, and keyboard navigation.
- **Compound Component Hierarchies**: Complex surfaces (e.g., `Carousel`, `Chart`, `Table`, `Form`, `Corkboard`, `Sketchpad`) use React Context providers and subcomponents, with strict runtime enforcement against out-of-context mounting.
- **Controlled & Uncontrolled Flexibility**: Form controls and interactive widgets support both controlled and uncontrolled usage patterns with seamless ref forwarding and custom styling via Tailwind class merges (`cn`).

## Side Effects

The package utilizes React lifecycle hooks, browser event listeners, timers, and canvas drawing pipelines for dynamic behaviors:

- `[arrow.tsx:Arrow]`: useLayoutEffect and window.addEventListener('resize') - Measures target DOM element bounding boxes and recomputes connecting SVG bezier vector curves upon layout shifts.
- `[attachment.tsx:Attachment]`: useLayoutEffect - Measures attachment container dimensions to dynamically scale media thumbnails and file metadata badges.
- `[boil.tsx:Boil]`: useEffect and setInterval timer - Cycles procedural turbulent SVG filter displacement seeds at configurable intervals (default 150ms) to produce animated hand-drawn line boiling motion.
- `[calendar.tsx:Calendar]`: useEffect - Synchronizes month navigation view state with external controlled date props.
- `[carousel.tsx:Carousel]`: useEffect - Subscribes to Embla Carousel API events ('select', 'reInit') and synchronizes canScrollPrev / canScrollNext states.
- `[chart.tsx:ChartContainer]`: useLayoutEffect, ResizeObserver, and window resize listeners - Monitors container width and height to calculate dynamic SVG coordinates, tooltips, and legends.
- `[code-block.tsx:CodeBlockCopy]`: useEffect and setTimeout timer - Copies code snippet text to clipboard via navigator.clipboard and resets copied feedback state after a 2000ms delay.
- `[combobox.tsx:Combobox]`: useEffect - Coordinates virtualized scroll positioning, search filtering, and outside-click dismiss event listeners.
- `[command.tsx:Command]`: useLayoutEffect - Coordinates cmdk input focus, dynamic list height adjustments, and key navigation highlights.
- `[confetti.tsx:Confetti]`: useEffect - Triggers 2D particle simulation on canvas/DOM upon mount or trigger call, updating velocities and particle lifetimes.
- `[corkboard.tsx:Corkboard]`: useLayoutEffect, pointer event listeners, and setTimeout timers - Tracks pointer drag coordinates, maintains note z-index ordering, and updates pinned note offsets on the cork surface.
- `[date-picker.tsx:DatePicker]`: useEffect - Synchronizes popover open state and calendar selection dates.
- `[direction.tsx:DirectionProvider]`: useLayoutEffect - Sets the document or root DOM element 'dir' attribute ('ltr' or 'rtl') to match reading direction.
- `[dropzone.tsx:Dropzone]`: useEffect - Registers drag-and-drop DOM listeners ('dragenter', 'dragover', 'dragleave', 'drop') on container ref.
- `[marquee.tsx:Marquee]`: useLayoutEffect - Measures track and container widths to configure seamless infinite CSS marquee loops and dynamic velocity.
- `[notebook.tsx:Notebook]`: useEffect - Coordinates page-turn flip animations and page index state transitions.
- `[peel-corner.tsx:PeelCorner]`: requestAnimationFrame loop and setTimeout timer - Simulates dynamic corner curl physics and spring release animations upon hover/pointer interactions.
- `[prompt-input.tsx:PromptInput]`: useEffect and useLayoutEffect - Auto-resizes textarea element based on scrollHeight and synchronizes action button activation states.
- `[rating.tsx:Rating]`: useEffect and addEventListener - Handles keyboard navigation (ArrowLeft, ArrowRight) and pointer hover preview calculations.
- `[reveal.tsx:Reveal]`: useLayoutEffect - Computes container bounding rects to generate animated clip-path reveal transitions.
